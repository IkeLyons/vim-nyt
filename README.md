## Vim NYT
Who hasn't wanted vim(like) bindings for NYT games???

Instead of modes like in VIM, I opted to use caps for simplicity. Caps lock can be used for a mode-like experience. 
- `H,J,K,L` for navigation directions ( `up, down, left, right` respectively).
  - `h,j,k,l` will enter those letters like normal
  - use caps lock/shift
- `G-ClueNum-Enter` to navigate to ClueNum respecting your current direction
  - Any key other than `Enter` will exit the buffer
